JAIRO Cloud

　JAIRO Cloud（WEKO3）より利用開始された利用機関におかれましてはご放念ください。

以下の資料にてご案内しておりました通り、2027年3月末を以ちまして

※「本番移行_移行仕様について（2023-08-31）.pdf」p.44参照

利用機関の皆様におかれましては、下記をご一読の上、
必要に応じてご対応をお願いいたします。

●影響
以下のようなリダイレクトが行われなくなります。

・Yハンドル（WEKO2）のURL → JAIRO Cloud（WEKO3）のURL
・DOIのURL → Yハンドル（WEKO2）のURL → JAIRO Cloud（WEKO3）のURL

IRDBやCiNii Research、DOIのリンク先としてYハンドルのURLが使われている場合、
これらのリンクからJAIRO Cloudのアイテム詳細画面へアクセスできなくなります。

●該当アイテムの確認方法

1. IRDB（https://irdb.nii.ac.jp/）にアクセス
2. 以下の条件を入力し検索
　・簡易検索欄：http://id.nii.ac.jp/
　・詳細検索の機関欄：[　自機関の機関名　]　※途中まで入力すると表示される候補から選択
3. ヒットしたアイテムの詳細画面を開き「資源識別子」欄を確認
4. 記載されているURIが「http://id.nii.ac.jp/xxxx/xxxxxxxx」であるアイテムが該当いたします

参考）IRDBサポート＞マニュアル＞検索
https://support.irdb.nii.ac.jp/ja/about/manual/search

●お願い
該当するアイテムについて、リダイレクト終了までに次のご対応をお願い致します。

1. 更新日時（datestamp）の更新（アイテムの空更新）を行う
2. OAI-PMHの出力をONにする　※必要に応じて

上記を実施することで、該当するアイテムがIRDBに再ハーベストされます。
その後、CiNii Research等、各種連携先のYハンドル（WEKO2）のURLが、
順次JAIRO Cloud（WEKO3）のURLに更新されます。
具体的な手順は以下リンク先もご参照ください。

## JAIRO Cloud サーバ障害に係るGakuNin RDM×JAIRO Cloud連携機能の不具合について（2026-10-16～10-21）
2026-10-26 15:51 頃

```
JAIRO Cloud利用機関
ご担当者　様

平素より大変お世話になっております。 
JAIRO Cloud事務局です。 

10月16日（金）から21日（水）にかけて断続的に発生したJAIRO Cloudのサーバ障害の影響で、
GakuNin RDM×JAIRO Cloud連携機能（GJ連携）によるアイテム登録が完了できない事象が発生していましたので、
お知らせいたします。

■ 発生日時
・2026年10月16日（金）9:15頃 - 13:30
・2026年10月17日（土）16:23 - 20:43、および 22:41 - 10月18日（日）3:04
・2026年10月20日（火）9:07 - 14:30
・2026年10月20日（火）19:40 - 10月21日（水）15:14

■ 障害内容
JAIRO Cloud側のSWORD API設定において登録方式が「ワークフロー登録」の場合、上記時間帯にGJ連携によってJAIRO Cloudに登録されたアクテビティがロックされ、編集・承認・強制終了ができない場合がある。

■ お願い
上記の状態になったアクティビティにつきましては、以下のご対応をお願いいたします。

・以下のWebフォームより「1. アクティビティの強制終了依頼」を行う。
https://forms.gle/rKKi4We2poN2FJZu8
※「補足」で「GJ連携によるアイテムである」ことを簡単で結構ですのでお伝えください。
・アクティビティの登録ユーザーに再度GJ連携を行うよう依頼する。

■ 参考
各アクティビティの登録ユーザーが誰か不明な場合は、アクティビティに記載されたメールアドレスから、JAIRO Cloud統合認証システムの会員情報検索によってご確認いただけます。
※JAIRO Cloud基本マニュアル＞ユーザーアカウント管理＞4．ユーザーアカウント情報の検索
https://jpcoar.org/support/jairo-cloud/manual/user-account/

本メールに関するお問い合わせは、署名欄記載のアドレスまでお願いいたします。

本件のご連絡が遅くなりましたことにつきまして、お詫び申し上げます。
何卒よろしくお願い申し上げます。
```
