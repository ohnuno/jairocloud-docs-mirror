# 補足
JAIRO Cloudでは、特定のIPアドレス及びユーザーエージェント（外部ボット等）からの大量アクセスによるサーバー高負荷のため、以下のような障害が頻発する問題への対策として緊急アップデートを実施しました。

本アップデート後も、大量アクセスを完全に防げるものではないため、引き続きアクセス制御の状況の調査等を行い、対応を継続して参ります。

- 障害内容

  - JAIRO Cloudへアクセスした際に「502 Bad Gateway」等のエラーが表示される
  - リポジトリの画面遷移に大幅な時間がかかる、または接続できない
